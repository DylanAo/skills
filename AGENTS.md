# Skill repository conventions

- This directory is the source repository for this user's reusable skills. Put new skills in their own lowercase, hyphenated directories at the repository root.
- Each skill requires `SKILL.md`; add `agents/openai.yaml` and supporting resources only when useful. Keep repository-wide documentation in the root README.
- Keep the root README Chinese first, then English. Update both skill catalogs when adding or removing a skill.
- Keep examples portable and free of personal paths, private learning materials, credentials, and local session details.
- Installed skills are deployment copies. Edit the repository source first; when installation or synchronization is authorized, update the matching installed skill without changing unrelated skills.
- Do not invent a repository URL, author identity, or license. GitHub publication and license selection follow the user's instructions.
